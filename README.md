# 荒野生存：網頁遊戲原型

這是一個使用 HTML、CSS 和原生 JavaScript 製作的最小生存遊戲原型。

## 執行方式

使用瀏覽器開啟 `index.html`，或在終端機執行：

```powershell
python -m http.server 8000
```

然後開啟 <http://localhost:8000>。

## 操作方式

- 移動：方向鍵或 `W`、`A`、`S`、`D`
- 攻擊：靠近敵人時自動攻擊
- 收集：靠近木材或石頭
- 治療：木材 2
- 收集資源和擊敗敵人可獲得經驗
- 每次升級會進化角色並強化攻擊
- 玩家角色採用橘色數碼恐龍風格造型
- 達到 10 級時可在火焰龍、機械龍、光明龍中選擇進化路線
- 每個敵人會隨機出現牙怪或史萊姆怪
- 每次升級會隨機提供三項技能選擇
- 清除本回合怪物後進入下一回合，每回合怪物數量增加 1 隻
- 角色支援移動行走、攻擊揮動與受傷閃爍動態效果
- 頂部會顯示遊戲經過時間；死亡或選擇升級介面時暫停
- 可使用「暫停」按鈕暫停或繼續，並可在暫停畫面重新開始
- 地圖大小為原來的 3 倍，畫面會跟隨角色移動
