# 荒野生存：網頁遊戲原型

這是一個使用 HTML、CSS 和原生 JavaScript 製作的最小生存遊戲原型。

## 執行方式

使用瀏覽器開啟 `index.html`，或在終端機執行：

```powershell
python -m http.server 8000
```

然後開啟 <http://localhost:8000>。

## 操作方式

- 移動：方向鍵或 `W`、`A`、`S`、`D`
- 攻擊：靠近敵人時自動攻擊
- 收集：靠近木材或石頭
- 製作斧頭：木材 3＋石頭 2
- 治療：木材 2
- 收集資源和擊敗敵人可獲得經驗
- 每次升級會進化角色並強化攻擊
- 玩家角色採用橘色數碼恐龍風格造型
- 達到 10 級時可在火焰龍、機械龍、光明龍中選擇進化路線
