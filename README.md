# 荒野生存：網頁遊戲原型

這是一個使用 HTML、CSS 和原生 JavaScript 製作的最小生存遊戲原型。

## 執行方式

使用瀏覽器開啟 `index.html`，或在終端機執行：

```powershell
python -m http.server 8000
```

然後開啟 <http://localhost:8000>。

## 操作方式

- 移動：方向鍵或 `W`、`A`、`S`、`D`
- 收集：靠近木材或石頭
- 製作斧頭：木材 3＋石頭 2
- 治療：木材 2
- 避開紅色敵人
